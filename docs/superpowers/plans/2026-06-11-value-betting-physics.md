## Context

Verified 2026-06-11 (firsthand, numeric repro + independent dataset recomputation): the survival backtest pays **winning NO bets at the YES leg's odds** — `compute_bet_pnl`/`_compute_pnl` use `entry_price`/`bet.price` (always the YES mid) for BOTH sides. A NO win at yes-mid 0.10 pays $45.00 where the economically correct payout is $0.56 (81x). Always-favorite's headline +$8,451.06 decomposes into NO-side +$8,759.98 / YES-side −$308.92 and becomes **−$660.93** under side-correct pricing; the learner's own v2 P&L is 79-91% NO-side. The market itself is calibrated (observed win rate tracks price per 0.1-bin; no exploitable favorite-longshot bias). User decision: fix the physics, give the brain price awareness, re-pick the seed for earnings-under-survival, re-run everything as finetune chapter 3. Honest expectation (accepted): headlines will shrink or go negative — that is the point.

## Goal

1. **Realism rule #3 — side-correct pricing**: winners pay `size*(winning_price/eff − 1)` where `eff = yes_price` (YES) or `1 − yes_price` (NO). Shared by poller, sweep scorer, archetype + static baselines.
2. **Side-aware entry floor**: the EFFECTIVE price of the taken side must be ≥ 0.05 at bet time (the row-level yes-mid floor stays for universe comparability).
3. **Value-betting decision mode**: `decide(price=...)` → `p_model = clamp(price + κ·fused)`, EV side selection, `min_edge` gate, odds-aware Kelly `f* = edge/(1−q)`. Legacy mode byte-identical when `price=None`.
4. **Earnings-aligned sweep**: LHS 8→10 dims (`min_edge`∈[0,0.15], `kappa`∈[0.05,0.5]), t-stat gate, rank by total PnL, top-5 validated in the real sequential survival season → v3 seed.
5. **Journey v3**: archive v2 as `*_run2`, re-run numerical + AI(MiniMax) + AI(Gemini), finetune-log chapter 3, /docs + README sync, deploy.

## Design decisions (locked, with rationale)

1. **`p_model = clamp(price + kappa*fused, 0, 1)`** — market prior + signal tilt. A naive `(1+fused)/2` anchor makes zero-signal ⇒ p=0.5 ⇒ systematically fade every non-0.5 price on no information (pathology checked against the calibrated dataset). With the price anchor, zero signal ⇒ zero edge ⇒ abstain. `kappa` is the tilt scale, sweepable.
2. **Kelly `f* = edge/(1−q)`** — exact reduction of classical Kelly `(pb−(1−p))/b` with `b=(1−q)/q`, `p=q+edge`. Replaces the even-money proxy only in value mode. `desired = rho_eff · f* · mean_confidence · bankroll` (rho + confidence dampeners kept — preserves the advisor lever and sizing semantics).
3. **Flags default OFF below the export layer** (realism-v2 convention): `side_correct_pricing: bool = False` on `compute_bet_pnl`/`_compute_pnl`/poller field/loop ctor; `value_betting: bool = False` on loop ctor; `price: float | None = None` on decide(); engine ctor `min_edge=0.0, kappa=0.25, entry_price_floor=None`. ONLY `run_survival_export` flips `side_correct_pricing=True, value_betting=True` by default.
4. **Side-aware floor placement (review-r1 M-3 + r3 L-1: TWO floor knobs, decoupled from value mode AND from the v2 row floor)**: the bet-level side-aware floor is a NEW, SEPARATE parameter `effective_entry_price_floor: float | None` (default `None` at every low layer) — the v2 `entry_price_floor` keeps its EXACT v2 meaning (row-universe yes-mid filter), so the v2 rollback stays byte-for-byte (`effective_entry_price_floor=None` reproduces v2 physics; r3 L-1). **At `run_survival_export` ONLY, the default is the typed sentinel `MIRROR_ROW_FLOOR: Final[float] = -1.0` (r5 M-1: omitted ⇒ resolve to `entry_price_floor`'s value; explicit `None` ⇒ disabled; any other float ⇒ that value — `None` cannot carry both meanings); the RESOLVED value is what threads downstream and lands in the summary key.** Enforcement points whenever `effective_entry_price_floor` is set, regardless of value mode — ALL FIVE decision surfaces (r4 M-1 completed the class): (a) decide() value mode (engine ctor `entry_price_floor` = the effective floor — the engine only ever sees the effective context); (b) `build_archetype_curve` (skip: pnl 0, `is_bet=False`, curve length stays = len(rows); RNG draw BEFORE the floor check); (c) **`score_config` post-decision check** — a BET whose effective side price < floor is SKIPPED (counts as no-bet) even in legacy mode, so `--realism` without `--value` cannot resurrect the mirrored NO-side lottery; (d) **the sequential loop**: `effective_entry_price_floor` threads `run_survival_season → _build_life_loop → SandboxPhase2Loop`, and a post-decide gate before `place_order` (`sandbox_phase2_loop.py:1595`) converts a BET whose `effective_entry_price(side, inputs.price)` < floor into a NO_BET record (reason `effective_price_below_floor`) — so `value_betting=False + effective floor` cannot place legacy sub-floor bets that only the invariant would catch, late; (e) **`build_static_baseline_curve`** applies the same post-decision gate around its decide() at `:1815-1829`. (f) The export physics invariant remains the fail-closed backstop (raises before write). NOT placed inside `compute_bet_pnl` (codex fix_second_order concur: silently zeroing already-placed bets would desync settlement/breath accounting). CLI `--realism` sets BOTH floors to 0.05 + cap 100 + side-correct. `always_favorite` never trips the floor (eff ≥ 0.5 by construction); `random` can.
5. **In-export physics invariant (review-r1 H-1: covers baselines, not just the learner; r5 M-2: covers PLACED bets, not just settled)**: join by `market_id` and recompute pnl from first principles (`compute_bet_pnl(..., side_correct_pricing=..., max_pnl_usd=...)`) for (a) every settled `recorder.steps` entry AND (b) every `is_bet=True` point of ALL THREE baseline curves (static/random/always_favorite — `BaselinePoint` carries market_id/side/size_usd/pnl_usd, all the recompute needs); `RuntimeError` on |Δ|>1e-6 BEFORE write_text. Skipped baseline points must satisfy `is_bet=False ⇒ size_usd==0 and pnl_usd==0` and (when derivable) the effective-floor reason. **The effective-floor check runs over ALL PLACED learner BetRecords, sourced per r8 H-1 (the recorder has NO placed-bet ledger today and `run_survival_export` deletes the temp `state_root` before validation, `survival_season.py:2441-2465`): `run_survival_season` reads each life's `open_bets.jsonl` (written by the executor's state_writer) immediately after the life ends — BEFORE temp-dir cleanup — and accumulates the records into a new `SurvivalRecorder.placed_bets` list that the export validator consumes. ~55% of placed bets never settle and would otherwise evade the backstop (r5 M-2); the pnl recompute stays settled-only.** Also `min_effective_entry_price >= floor` across placed learner bets + baseline bets. A baseline-side physics bug can therefore never certify an artifact. New summary evidence keys (6): `side_correct_pricing, value_betting, min_edge, kappa, effective_entry_price_floor, min_effective_entry_price`.
6. **Sweep objective**: `t_stat = sharpe*sqrt(bets)` on SweepMetrics; `rank_configs_by_pnl(scored, *, min_bets, min_t_stat)` filters `bets>=min_bets AND t_stat>=min_t_stat` (falls back to the unfiltered pool if empty — same convention as `rank_configs`) then sorts by `net_pnl` desc. Fast scorer ranks; **top-5 validated in the real sequential season** (breath/death/respawn) via `run_survival_export` to temp out_paths with the SAME knobs as the journeys (fragile 0.95, loss_multiplier 5.0, breath 35, max_lives 12); final ranking: finished-alive DESC, then season terminal PnL DESC. Winner serialized to `reports/backtest/value_seed_v3.json` (weights via `model_dump()`).
7. **v2 artifacts archived** as `survival_journey{,_ai,_ai_gemini}_run2.json` (deploy-only, gitignored; add the missing gemini_run* ignore line). v3 takes the primary filenames. Dashboard gains 3 archived modes (8 total).
